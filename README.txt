Belonging in Practice — favicon patch
Prepared November 16, 2026 from the current live page.

This patch adds explicit browser-tab and Apple home-screen icon links using the established green sprout artwork from the Conditions Practice family. No app content or functionality has been changed.

1. Unzip this download.
2. Open the existing Belonging in Practice project or complete site folder.
3. Copy the four files INSIDE site-files into that site's root, replacing files with the same names. Do not upload the site-files folder as a nested folder.
4. Publish the complete existing project or site folder to its existing Netlify site.

Do not deploy this patch folder alone: Netlify deployments replace the deployed files, and this patch intentionally contains only index.html and the three icons. Keep all other existing scripts, styles, media, and configuration files.

If you have changed the page since this patch was prepared, preserve those changes and copy only the three icon link tags immediately before </head> from the included index.html into your newer index.html, along with the icon files.

The versioned icon links help browsers refresh the icon. If a tab still shows the previous icon, close and reopen that tab.
